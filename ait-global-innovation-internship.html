Startup Case Study · GIIP 2026 Project AIT Innovation Labs

BusSetu Transit Platform

A real-time public transit tracking and route optimization platform engineered to eliminate commuter uncertainty across regional transport networks.

Problem Statement

Commuters in regional transport corridors face severe timetable uncertainty, zero real-time vehicle visibility, and frustrating long wait times due to uncoordinated dispatch data.

Solution Architecture

BusSetu ingests GTFS static schedule files and blends them with real-time GPS telemetry streams to compute accurate arrival ETA projections on interactive vector maps.

My Role as Lead Architect

Engineered the full-stack system architecture, built low-latency map visualizers, integrated Google Maps APIs, and presented the working prototype before AIT faculty.

Technologies & Stack

JavaScript (ES6+) Node.js Google Maps API GTFS Parser HTML5 / CSS3 RESTful API Vercel Edge
